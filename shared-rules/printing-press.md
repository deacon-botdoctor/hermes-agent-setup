# Printing Press full discovery and proof

Printing Press includes a reusable tool catalog, the full `printing-press` skill,
and the separate `cli-printing-press` engine. A catalog search is one discovery lane.
When asked to print a service or build an integration, load the full skill and its
fleet contract at `skills/printing-press/references/fleet-contract.md`.

A catalog miss must continue through official provider docs/specs, public source and
package searches, applicable authorized browser evidence, and the owning runtime's
capability inventory. Record evidence and reasons for each rejected candidate.
Reuse a suitable existing tool before generating another one.

Run the applicable engine legs and retain their output and exit codes. A `vision`
template is not research; failed spec discovery or empty sniff results are not proof
that no integration exists. Continue independent discovery after an engine failure.

Report Complete Press only when every applicable lane and required verification gate
passes. Report Partial Press when research or artifacts exist but required evidence
is missing. Report Blocked Press only after authorized routes are exhausted, with the
exact missing input and resume condition. Browser-session proof establishes only the
observed UI behavior. Installed files do not prove invocation or a usable integration.

Use the owning client's runtime and authorized connections. Keep credentials, cookies,
client identity, and customer data out of shared artifacts. Existing authority governs
writes and live checks; invoking this skill does not authorize public publishing.
Sanitize reusable tools and preserve provenance, license, verification, and rollback
before any separately authorized catalog promotion.
